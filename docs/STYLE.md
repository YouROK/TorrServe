# Стиль приложения TorrServe Silo

Единые правила оформления. Палитра — из веб-версии Silo (`values/silo_colors.xml`).
Эталон акцента — боковое меню: активный пункт подсвечивается **янтарным**, обычный — серый.

## 1. Цвета

| Роль | Цвет |
|---|---|
| Активное/выбранное, акцент | `silo_amber` / `silo_amber_bright` |
| Обычная кнопка, рамка | `silo_border` / `silo_steel_bright` |
| Подложка при фокусе/наведении | `silo_surface_hover` |
| Опасное действие | `silo_danger` |
| Недоступно | `silo_text_faint` |

Янтарный = «выбрано/активно/главное». Серый = «обычное». Красный = «удалить/выйти».

## 2. Выбор одного значения из нескольких (chips / segmented buttons)

Это относится к любым переключателям «одно из N»: действия окна раздачи, пользователи,
вкладки типов файлов, аккаунты в настройках и т.п.

Правило:

- варианты — **кнопки** (chips) в ряд или столбиком, а не выпадающий список;
- **выбранная кнопка — янтарная** (янтарная заливка/подложка + янтарная рамка 2dp +
  янтарный текст), а не «серая выбранная»;
- невыбранная — обычная кнопка: прозрачный фон, рамка 1dp `silo_border`, светлый текст;
- **фокус (пульт) виден всегда**: подложка `silo_surface_hover` + рамка 3dp `silo_amber`;
- нажатие — как фокус, но рамка 2dp;
- размер: высота не меньше 40dp, отступы 16×9dp, радиус 8dp, текст 14sp; на телефоне
  кнопки могут растягиваться на всю ширину;
- начальный фокус окна — на выбранной (или сохранённой по умолчанию) кнопке.

Реализация: `ui/SiloChip` + `drawable/silo_choice_bg.xml` + `color/silo_choice_text.xml`;
для XML — стиль `@style/SiloChoice`.
Новые переключатели делать только через `SiloChip`, свои drawable/цвета не заводить.

Длинные списки (сортировка, категории, выбор плеера, меню торрента) остаются диалогами:
для 2–5 значений — `SiloChip`, для длинного списка — диалог; выбранный пункт в диалоге
помечается янтарным.

## 3. Кнопки

- Основная — `SiloButtonPrimary`: янтарная заливка, тёмный текст, фокус — ярче + рамка 2dp.
- Обычная — `SiloButton`: прозрачная, рамка 1dp, светлый текст.
- Опасная — как обычная, текст `silo_danger`.

## 4. Меню

Пункт меню — `SiloNavItem`: обычный серый, выбранный — серая подложка + янтарная полоса
слева + янтарный текст/иконка. Меню — эталон янтарного акцента, но кнопки выбора
делаются по правилу из п. 2 (янтарная кнопка, а не серая).

## 5. Окно раздачи из другого приложения

- одно окно, внутри — страницы (действие → файлы → предзагрузка → плеер);
- кнопки действий — `SiloChip`, выбранное действие янтарное;
- фокус ставится на выбранную кнопку при получении фокуса окном (ТВ/пульт);
- галочка «Запомнить действие и пользователя» — временная: при открытии окна снята,
  включённая сохраняет действие и пользователя по умолчанию, снятая не меняет сохранённое.
