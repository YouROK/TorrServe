# Инструкции для агента

## Правила работы

1. Любая правка, затрагивающая больше 2–3 файлов, начинается с плана в `PLAN_TODO.md`
   в корне проекта: список задач с чекбоксами, в порядке выполнения.
2. План ведётся по ходу работы: задача помечается `[x]` сразу после проверки на устройстве,
   а не после написания кода.
3. Каждый пункт плана проверяется на приставке (`192.168.1.4:5555`) или эмуляторе:
   сборка → установка → скриншот/дамп UI → только потом отметка о выполнении.
4. Если проверка провалилась — пункт остаётся `[ ]`, а причина пишется в плане.
5. Большие решения и найденные особенности сервера фиксируются в `PLAN_SILO_CLIENT.md`
   (постоянный документ), чтобы не терять контекст между итерациями.
6. Не трогать `ru.yourok.torrserve` (старый клиент MatriX) и чужие процессы сервера.
7. Библиотеку пользователя не изменять без необходимости; тестовые данные удалять за собой.

## Сборка и установка

```bash
export ANDROID_USER_HOME=$PWD/.android-home GRADLE_USER_HOME=$PWD/.gradle-home
./gradlew :app:assembleDebug --no-daemon
adb -s 192.168.1.4:5555 install -r app/build/outputs/apk/debug/app-debug.apk
```

## Локальный сервер

8. Локальный сервер (запускается приложением на приставке) **всегда** работает на порту **8090**.
   Менять этот порт нельзя: ни автоподбором, ни настройкой, ни «если занято».
   Если 8090 занят - это ошибка, которую нужно показать пользователю, а не обходить сменой порта.
   Константа порта: `TorrService.LOCAL_PORT = 8090`, адрес клиента: `Prefs.LOCAL_URL`.
9. Внешний (удалённый) сервер может быть на любом порту - его адрес вводится вручную
   или находится поиском в сети, ограничений на порт нет.
