## Предзагрузка: разбор (итерация 8)

- [x] Причина 1: прогресс считался от размера всего файла (1,4 ГБ) вместо окна предзагрузки (16 МБ) - шкала стояла около нуля.
- [x] Причина 2: вызов `preload` падал с `file index out of bounds` - id файла из `file_stats` не совпадает с индексом в движке для части раздач.
- [x] Причина 3: готовность определялась по `preloaded_bytes`, а он у части раздач остаётся 0 - ждали до таймаута.
- [x] Решение: прогресс = `filled` из `/api/torrents/:hash/cache` относительно `preload_size`; готовность = реальная проверка потока (Range 0-64КБ) - если сервер отдаёт байты, сразу запускаем плеер.
- [x] Проверено на Heart of the Beast: 1,5 с - диалог закрылся, открылся Vimu.

## Предзагрузка: финальный разбор (итерация 9)
